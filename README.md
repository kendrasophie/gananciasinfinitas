# Ganancias infinitas

Agenda privada para registrar servicios de traslado. La app no guarda datos en este repositorio:
los viajes se almacenan en una hoja de cálculo de Google Drive del dueño, protegida con clave.

Archivos: `index.html`, `styles.css`, `app.js`, `sw.js` (funcionamiento sin conexión), `manifest.webmanifest` e íconos.
